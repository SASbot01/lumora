**Grooming masculino de resultados.** Tienda de marca propia enfocada en la cortadora profesional Zero-Gapped — el acabado de barbería en casa. Marca creada con un barbero profesional (@jericostyle).

> *"Tu mejor versión no se hereda. Se trabaja."*

## Contenido del repo

### Web (maqueta)
- `site/` — tienda web (HTML/CSS/JS) con diseño dark premium, modelos 3D (Three.js), galería de producto y copy persuasivo.
  - Ejecutar en local: `cd site && python3 -m http.server 8765` → http://127.0.0.1:8765

- `02-HOMEPAGE-COPY.md` — copy de la home
